地理クエスト

バトルの攻撃手段が、地理の問題。

ファミコン風のフィールドを歩き、敵と出会うと4択の地理問題が出る学習RPG。問題は先生がスプレッドシートで差し替えでき、誰がどこでつまずいたかが自動で残ります。Chromebookのブラウザだけで動きます。

OVERVIEW

何ができるか

地理の一問一答を、経験値とレベルアップのある冒険に変えます。

スプレッドシートに1行ずつ問題を書くだけで、そのまま敵とのバトルに出てきます。生徒の解答は日時・正誤・かかった秒数つきで自動的に記録されます。

FEATURES

特徴

授業で実際に使うことを前提にした作りになっています。

🗺️

歩ける世界がある

48×48マスの大陸を歩きます。北に山脈、そこから流れる川、中央の平野に城と町が4つと村が3つ、西に森、南に砂漠、東に半島。川は橋を通らないと渡れません。歩いて地形を確かめられます。

⚔️

正解が攻撃、不正解が被弾

4択に正解すると敵にダメージが入り、間違えると自分がダメージを受けます。倒すと経験値が入り、レベルが上がるとHPが全回復します。町と村と城では休めて、敵も出ません。

🏜️

奥へ行くほど強い敵

地形が険しいほど敵が強く、出る問題も難しくなります（草原→森→砂漠の順にHP・攻撃力・経験値が上がる）。だから「まだ砂漠は早い」という手応えが生まれ、レベルを上げる理由ができます。敵の見た目は問題の分野ごとに変わります。

📊

問題はスプレッドシートの1行

問題文・選択肢4つ・正解番号・解説を1行書けば、それがそのまま出題されます。コードを触る必要はありません。分野と難易度も指定でき、地理以外の教科にも入れ替えられます。

🔁

間違えた問題がまた出る

一度間違えた問題は覚えておいて、あとでもう一度出します。正解できたらその問題は外れます。1回流して終わりにしないための仕組みです。

📝

つまずきが残る

誰が・どの問題を・何秒で解いて・正解したかが記録シートに貯まります。生徒側も「ぼうけんのしょ」で分野別の正答率を見られるので、自分の苦手が分かります。

🎮

音も絵もファイル不要

キャラも地形もドット絵をコードの中に文字で持ち、効果音はその場で波形を合成しています。だから貼り付けるファイルは3つだけ。画像も音声もアップロードしません。

👩‍🏫

答えは生徒に見えない

アプリは先生のアカウント名義で動くので、生徒はスプレッドシート自体を開けません。見えるのはゲーム画面だけです。

/**
 * 先生が最初に1回だけ実行する関数。
 * 4枚のシートを作り、サンプル問題を入れる。
 * 既にシートがある場合は中身を消さず、足りないものだけ足す。
 */
function setup() {
  const ss = SpreadsheetApp.getActiveSpreadsheet();

  const qSheet = ensureSheet_(ss, SHEET_QUESTION, HEADER_QUESTION);
  if (qSheet.getLastRow() <= 1) {
    const rows = buildSampleQuestions_();
    qSheet.getRange(2, 1, rows.length, HEADER_QUESTION.length).setValues(rows);
    qSheet.setColumnWidth(4, 320);
    qSheet.setColumnWidth(10, 320);
  }

  ensureSheet_(ss, SHEET_LOG, HEADER_LOG);
  ensureSheet_(ss, SHEET_PROGRESS, HEADER_PROGRESS);

  const cSheet = ensureSheet_(ss, SHEET_CONFIG, HEADER_CONFIG);
  if (cSheet.getLastRow() <= 1) {
    cSheet.getRange(2, 1, DEFAULT_CONFIG.length, HEADER_CONFIG.length).setValues(DEFAULT_CONFIG);
    cSheet.setColumnWidth(2, 260);
    cSheet.setColumnWidth(3, 400);
  }

  // 既定のシート「シート1」が空のまま残っていたら消す
  const first = ss.getSheetByName('シート1') || ss.getSheetByName('Sheet1');
  if (first && ss.getSheets().length > 1 && first.getLastRow() === 0) {
    ss.deleteSheet(first);
  }

  Logger.log('セットアップ完了。問題シートに ' + Math.max(0, qSheet.getLastRow() - 1) + ' 問入っています。');
  return 'セットアップ完了';
}

/**
 * 初回アクセス時にシートが無ければ自動で作る。
 * 先生がGASエディタで setup を実行しなくても、URLを開いた時点で使い始められる。
 * 授業の開始直後に全員が同時にアクセスしても二重にサンプル問題が入らないよう、
 * 準備が要るときだけロックを取る。
 */
function ensureInitialized_(ss) {
  const qSheet = ss.getSheetByName(SHEET_QUESTION);
  if (qSheet && qSheet.getLastRow() > 1) return;   // 準備済み。ここが大半のケース

  const lock = LockService.getScriptLock();
  if (!lock.tryLock(15000)) return;                // 他の人が初期化中なら任せる
  try {
    const again = ss.getSheetByName(SHEET_QUESTION);
    if (again && again.getLastRow() > 1) return;   // ロック待ちの間に誰かが終わらせた
    setup();
  } catch (err) {
    Logger.log('初期化に失敗: ' + err.message);
  } finally {
    lock.releaseLock();
  }
}

function ensureSheet_(ss, name, header) {
  let sheet = ss.getSheetByName(name);
  if (!sheet) {
    sheet = ss.insertSheet(name);
  }
  const current = sheet.getRange(1, 1, 1, header.length).getValues()[0];
  const needHeader = current.join('') === '' || current[0] !== header[0];
  if (needHeader) {
    sheet.getRange(1, 1, 1, header.length).setValues([header]);
    sheet.getRange(1, 1, 1, header.length).setFontWeight('bold').setBackground('#e8eaf6');
    sheet.setFrozenRows(1);
  }
  return sheet;
}

/**
 * ゲーム起動時に1回だけ呼ばれる。
 * 問題を全件と、その生徒の進捗をまとめて返す。
 * 以後は通信せずブラウザ側だけでゲームが進む(同時実行数を節約するための設計)。
 */
function getGameData(playerName, className) {
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    ensureInitialized_(ss);
    const config = readConfig_(ss);

    const qSheet = ss.getSheetByName(SHEET_QUESTION);
    if (!qSheet || qSheet.getLastRow() <= 1) {
      return { ok: false, message: '問題シートが空です。GASエディタで setup を実行してください。' };
    }

    const values = qSheet.getRange(2, 1, qSheet.getLastRow() - 1, HEADER_QUESTION.length).getValues();
    const fieldFilter = String(config['出題分野'] || '').split(',').map(function (s) { return s.trim(); }).filter(String);

    const questions = [];
    values.forEach(function (row, i) {
      const text = String(row[3] || '').trim();
      const answer = parseInt(row[8], 10);
      if (!text || !answer) return;
      const field = String(row[1] || 'その他').trim();
      if (fieldFilter.length && fieldFilter.indexOf(field) === -1) return;

      const choices = [row[4], row[5], row[6], row[7]].map(function (c) { return String(c == null ? '' : c).trim(); });
      if (choices.filter(String).length < 2) return;
      if (answer < 1 || answer > choices.length) return;
      // 正解に指定された選択肢が空欄だと、その問題は永久に正解できなくなる。出題しない
      if (!choices[answer - 1]) return;

      questions.push({
        id: String(row[0] || ('Q' + (i + 1))),
        field: field,
        level: Number(row[2]) || 1,
        text: text,
        choices: choices,
        answer: answer,
        note: String(row[9] || '').trim()
      });
    });

    if (!questions.length) {
      return { ok: false, message: '出題できる問題がありません。問題シートを確認してください。' };
    }

    const progress = (playerName && className) ? readProgress_(ss, className, playerName) : { level: 1, exp: 0 };

    return {
      ok: true,
      questions: questions,
      progress: progress,
      config: {
        classes: String(config['クラス名'] || '').split(',').map(function (s) { return s.trim(); }).filter(String),
        encounterRate: clampNumber_(config['エンカウント率'], 1, 60, 8),
        expPerLevel: clampNumber_(config['レベルアップ必要経験値'], 1, 9999, 20),
        soundEnabled: String(config['効果音'] == null ? 'ON' : config['効果音']).trim().toUpperCase() !== 'OFF'
      }
    };
  } catch (err) {
    return { ok: false, message: '読み込みに失敗しました: ' + err.message };
  }
}

/**
 * 名前が決まったあとに、その生徒の続きだけを取りに行く軽い関数。
 * 問題は起動時に取得済みなので、ここでは進捗しか読まない。
 */
function getProgress(playerName, className) {
  try {
    if (!playerName || !className) return { ok: true, progress: { level: 1, exp: 0 } };
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    return { ok: true, progress: readProgress_(ss, String(className).trim(), String(playerName).trim()) };
  } catch (err) {
    return { ok: false, progress: { level: 1, exp: 0 } };
  }
}

/**
 * 解答ログと進捗をまとめて保存する。
 * 1問ごとではなく、10問たまった時とゲーム終了時にだけ呼ばれる。
 */
function saveSession(payload) {
  const lock = LockService.getScriptLock();
  // 待ちすぎない。取れなければ失敗を返し、クライアント側が次回にまとめて送り直す
  if (!lock.tryLock(8000)) {
    return { ok: false, retry: true, message: '混み合っています' };
  }
  try {
    const ss = SpreadsheetApp.getActiveSpreadsheet();
    const className = sanitizeCell_(payload && payload.className);
    const playerName = sanitizeCell_(payload && payload.playerName);
    if (!className || !playerName) {
      return { ok: false, message: '名前とクラスが未設定です' };
    }

    const logs = (payload && payload.logs) || [];
    // 1回で受け取る上限。超えた分は保存されないので、クライアント側で分けて送る
    if (logs.length > 200) {
      return { ok: false, retry: true, message: '一度に送れるのは200件までです' };
    }
    if (logs.length) {
      const logSheet = ss.getSheetByName(SHEET_LOG) || ensureSheet_(ss, SHEET_LOG, HEADER_LOG);
      const rows = logs.map(function (l) {
        return [
          new Date(),
          className,
          playerName,
          sanitizeCell_(l.questionId),
          Number(l.selected) || 0,
          l.correct ? '○' : '×',
          Math.round((Number(l.seconds) || 0) * 10) / 10,
          Number(l.level) || 1
        ];
      });
      logSheet.getRange(logSheet.getLastRow() + 1, 1, rows.length, HEADER_LOG.length).setValues(rows);
    }

    writeProgress_(ss, className, playerName, Number(payload.level) || 1, Number(payload.exp) || 0);
    return { ok: true };
  } catch (err) {
    return { ok: false, retry: true, message: '保存に失敗しました: ' + err.message };
  } finally {
    lock.releaseLock();
  }
}

// ===== 進捗の読み書き =====

function readProgress_(ss, className, playerName) {
  const sheet = ss.getSheetByName(SHEET_PROGRESS);
  if (!sheet || sheet.getLastRow() <= 1) return { level: 1, exp: 0 };

  const values = sheet.getRange(2, 1, sheet.getLastRow() - 1, HEADER_PROGRESS.length).getValues();
  for (let i = 0; i < values.length; i++) {
    if (String(values[i][0]).trim() === className && String(values[i][1]).trim() === playerName) {
      return { level: Number(values[i][2]) || 1, exp: Number(values[i][3]) || 0 };
    }
  }
  return { level: 1, exp: 0 };
}

function writeProgress_(ss, className, playerName, level, exp) {
  const sheet = ss.getSheetByName(SHEET_PROGRESS) || ensureSheet_(ss, SHEET_PROGRESS, HEADER_PROGRESS);
  const lastRow = sheet.getLastRow();

  if (lastRow > 1) {
    const values = sheet.getRange(2, 1, lastRow - 1, 2).getValues();
    for (let i = 0; i < values.length; i++) {
      if (String(values[i][0]).trim() === className && String(values[i][1]).trim() === playerName) {
        sheet.getRange(i + 2, 3, 1, 3).setValues([[level, exp, new Date()]]);
        return;
      }
    }
  }
  sheet.appendRow([className, playerName, level, exp, new Date()]);
}

// ===== 設定 =====

function readConfig_(ss) {
  const sheet = ss.getSheetByName(SHEET_CONFIG);
  const config = {};
  DEFAULT_CONFIG.forEach(function (row) { config[row[0]] = row[1]; });
  if (!sheet || sheet.getLastRow() <= 1) return config;

  const values = sheet.getRange(2, 1, sheet.getLastRow() - 1, 2).getValues();
  values.forEach(function (row) {
    const key = String(row[0] || '').trim();
    if (key) config[key] = row[1];
  });
  return config;
}

function clampNumber_(raw, min, max, fallback) {
  const n = Number(raw);
  if (!isFinite(n) || n < min || n > max) return fallback;
  return n;
}

/**
 * スプレッドシートに書き込む前に、先頭の = + - @ を無害化する。
 * 生徒が名前欄に数式を入れて他人のシートを壊すのを防ぐ(数式インジェクション対策)。
 */
function sanitizeCell_(value) {
  let s = String(value == null ? '' : value).trim().slice(0, 60);
  s = s.replace(/[\x00-\x1f\x7f]/g, '');
  if (/^[=+\-@\t\r]/.test(s)) s = "'" + s;
  return s;
}

  init: function () {
    if (this.ctx) return;
    try {
      const AC = window.AudioContext || window.webkitAudioContext;
      if (AC) this.ctx = new AC();
    } catch (e) { this.ctx = null; }
  },

  tone: function (freq, dur, type, vol, delay) {
    if (!this.enabled || !this.ctx) return;
    const t0 = this.ctx.currentTime + (delay || 0);
    const osc = this.ctx.createOscillator();
    const gain = this.ctx.createGain();
    osc.type = type || 'square';
    osc.frequency.setValueAtTime(freq, t0);
    gain.gain.setValueAtTime(vol || 0.05, t0);
    gain.gain.exponentialRampToValueAtTime(0.0001, t0 + dur);
    osc.connect(gain);
    gain.connect(this.ctx.destination);
    osc.start(t0);
    osc.stop(t0 + dur + 0.02);
  },

    if (!this.enabled || !this.ctx) return;
    const t0 = this.ctx.currentTime;
    const osc = this.ctx.createOscillator();
    const gain = this.ctx.createGain();
    osc.type = 'square';
    osc.frequency.setValueAtTime(from, t0);
    osc.frequency.exponentialRampToValueAtTime(Math.max(30, to), t0 + dur);
    gain.gain.setValueAtTime(vol || 0.05, t0);
    gain.gain.exponentialRampToValueAtTime(0.0001, t0 + dur);
    osc.connect(gain);
    gain.connect(this.ctx.destination);
    osc.start(t0);
    osc.stop(t0 + dur + 0.02);
  },

  // ノイズ（被弾のザッという音）
  noise: function (dur, vol) {
    if (!this.enabled || !this.ctx) return;
    const len = Math.floor(this.ctx.sampleRate * dur);
    const buf = this.ctx.createBuffer(1, len, this.ctx.sampleRate);
    const data = buf.getChannelData(0);
    for (let i = 0; i < len; i++) data[i] = (Math.random() * 2 - 1) * (1 - i / len);
    const src = this.ctx.createBufferSource();
    const gain = this.ctx.createGain();
    src.buffer = buf;
    gain.gain.value = vol || 0.05;
    src.connect(gain);
    gain.connect(this.ctx.destination);
    src.start();
  },

  seq: function (notes, vol) {
    let t = 0;
    const self = this;
    notes.forEach(function (n) {
      self.tone(n[0], n[1], 'square', vol || 0.05, t);
      t += n[1] * 0.9;
    });
  },

  // 以下、場面ごとの音
  select:    function () { this.tone(880, 0.05, 'square', 0.04); },
  decide:    function () { this.seq([[660, 0.05], [990, 0.09]], 0.05); },
  step:      function () { this.tone(180, 0.025, 'square', 0.018); },
  blocked:   function () { this.tone(110, 0.06, 'square', 0.03); },
  encounter: function () { this.sweep(1200, 160, 0.42, 0.055); },
  attack:    function () { this.seq([[520, 0.04], [780, 0.04], [1040, 0.09]], 0.05); },
  damage:    function () { this.noise(0.22, 0.05); this.tone(150, 0.2, 'sawtooth', 0.04); },
  defeat:    function () { this.seq([[880, 0.07], [740, 0.07], [590, 0.07], [440, 0.16]], 0.05); },
  levelup:   function () { this.seq([[523, 0.09], [659, 0.09], [784, 0.09], [1046, 0.26]], 0.055); },
  gameover:  function () { this.seq([[392, 0.14], [330, 0.14], [262, 0.14], [196, 0.36]], 0.05); },
  heal:      function () { this.seq([[523, 0.08], [784, 0.08], [1046, 0.18]], 0.045); }
};

let typingTimer = null;
function typeMessage(el, html, done) {
  const cursor = $('msgCursor');
  if (cursor) cursor.classList.remove('show');
  clearInterval(typingTimer);
  el.innerHTML = html;

  // テキストノードを集めて、いったん全部空にする
  const nodes = [];
  (function walk(n) {
    for (let i = 0; i < n.childNodes.length; i++) {
      const c = n.childNodes[i];
      if (c.nodeType === 3) { nodes.push({ node: c, text: c.nodeValue }); c.nodeValue = ''; }
      else walk(c);
    }
  })(el);

  let ni = 0, ci = 0;
  typingTimer = setInterval(function () {
    if (ni >= nodes.length) {
      clearInterval(typingTimer);
      const c = $('msgCursor');
      if (c && el.id === 'battleMessage' && el.textContent.trim()) c.classList.add('show');
      if (done) done();
      return;
    }
    const cur = nodes[ni];
    cur.node.nodeValue = cur.text.slice(0, ++ci);
    if (ci >= cur.text.length) { ni++; ci = 0; }
  }, 22);
}

function drawSprite(ctx, sprite, dx, dy, scale, flip) {
  for (let row = 0; row < sprite.length; row++) {
    const line = sprite[row];
    for (let col = 0; col < line.length; col++) {
      const ch = line[col];
      if (ch === '.' || ch === ' ') continue;
      const color = PALETTE[ch];
      if (!color) continue;
      const px = flip ? (line.length - 1 - col) : col;
      ctx.fillStyle = color;
      ctx.fillRect(dx + px * scale, dy + row * scale, scale, scale);
    }
  }
}

// ===== スプライトのキャッシュ =====
// 1ドットずつ塗る処理は重い。64x64のタイルを毎フレーム塗り直すと
// 画面全体で数十万回の描画になり、非力な端末では動かない。
// そこで各スプライトを起動時に一度だけ小さなCanvasへ焼いておき、
// 以後はその画像を貼るだけにする。
const spriteCache = {};

function bakeSprite(key, sprite, scale, flip) {
  const cached = spriteCache[key];
  if (cached) return cached;
  const c = document.createElement('canvas');
  c.width = sprite[0].length * scale;
  c.height = sprite.length * scale;
  const ctx = c.getContext('2d');
  ctx.imageSmoothingEnabled = false;
  drawSprite(ctx, sprite, 0, 0, scale, flip);
  spriteCache[key] = c;
  return c;
}

// 地形はタイルデータから描く。同じ絵が並んで格子模様に見えないよう、
// 座標からパターンを選び分ける。
function tileVariantIndex(type, wx, wy) {
  const variants = SPR_TILE[type];
  if (!variants || variants.length === 1) return 0;
  // 座標をかき混ぜて、規則的な縞にならないようにする
  return Math.abs(((wx * 73856093) ^ (wy * 19349663)) % variants.length);
}

// 地形が変わる辺に「にじみ」を描く。
// タイルを独立して描くと境界が直線で切れて地図に見えないので、
// 隣が別の地形の辺だけ、その地形らしい縁取りを重ねる。
const EDGE_STYLE = {
  // 水は岸に白波
  w: { color: '#ffffff', unit: 2, bump: 1, gap: 3 },
  // 道は土が草へにじむ
  r: { color: '#8d5524', unit: 3, bump: 2, gap: 2 },
  // 砂漠は砂が草へ散る
  d: { color: '#e8c98a', unit: 3, bump: 2, gap: 2 }
};

function edgeMask(wx, wy, sameSet) {
  let m = 0;
  if (!sameSet[tileAt(wx, wy - 1)]) m |= 1;
  if (!sameSet[tileAt(wx + 1, wy)]) m |= 2;
  if (!sameSet[tileAt(wx, wy + 1)]) m |= 4;
  if (!sameSet[tileAt(wx - 1, wy)]) m |= 8;
  return m;
}

const SAME_AS = {
  w: { w: true, b: true },     // 水と橋は地続き扱い
  r: { r: true, b: true, t: true, v: true, c: true },  // 道は町や城と繋がる
  d: { d: true }
};

function bakeEdged(key, sprite, scale, mask, style) {
  const cached = spriteCache[key];
  if (cached) return cached;

  const c = document.createElement('canvas');
  c.width = sprite[0].length * scale;
  c.height = sprite.length * scale;
  const ctx = c.getContext('2d');
  ctx.imageSmoothingEnabled = false;
  drawSprite(ctx, sprite, 0, 0, scale, false);

  const w = c.width, h = c.height;
  const u = Math.max(1, Math.round(style.unit * scale));
  ctx.fillStyle = style.color;

  // 辺に沿って、厚みを不規則に変えながら縁を置く
  function edge(horizontal, atFar) {
    const len = horizontal ? w : h;
    for (let i = 0; i < len; i += u) {
      const step = i / u;
      const t = u + ((step % style.gap === 0) ? u * style.bump : 0);
      if (horizontal) ctx.fillRect(i, atFar ? h - t : 0, u, t);
      else ctx.fillRect(atFar ? w - t : 0, i, t, u);
    }
  }
  if (mask & 1) edge(true, false);
  if (mask & 2) edge(false, true);
  if (mask & 4) edge(true, true);
  if (mask & 8) edge(false, false);

  spriteCache[key] = c;
  return c;
}

// 動く地形。止まった絵より、水が流れて草が揺れている方が生きた画面に見える。
// コマは起動時に焼いて使い回すので、動かしても速度は変わらない。
let tileFrame = 0;

function animSprite(type, vi, wx, wy) {
  const frames = SPR_TILE_ANIM[type];
  if (!frames) return null;
  // マスごとに位相をずらす。全部が同じ拍子で動くと機械的に見える
  const phase = Math.abs((wx * 3 + wy * 5)) % frames.length;
  return { sprite: frames[(tileFrame + phase) % frames.length],
           key: 'a' + type + ((tileFrame + phase) % frames.length) };
}

function drawTile(ctx, type, dx, dy, scale, wx, wy) {
  const variants = SPR_TILE[type];
  if (!variants) return;
  const vi = tileVariantIndex(type, wx, wy);

  // 動く地形は、その時のコマを使う（草はパターンを持つので1種類目だけ動かす）
  const anim = (type === 'w' || (vi === 0 && SPR_TILE_ANIM[type]))
    ? animSprite(type, vi, wx, wy) : null;
  const sprite = anim ? anim.sprite : variants[vi];
  const baseKey = anim ? anim.key : ('t' + type + vi);

  let img;
  const style = EDGE_STYLE[type];
  if (style) {
    const mask = edgeMask(wx, wy, SAME_AS[type]);
    img = mask
      ? bakeEdged('e' + baseKey + '_' + mask + '@' + scale, sprite, scale, mask, style)
      : bakeSprite(baseKey + '@' + scale, sprite, scale, false);
  } else {
    img = bakeSprite(baseKey + '@' + scale, sprite, scale, false);
  }
  ctx.drawImage(img, Math.round(dx), Math.round(dy));
}

function drawCachedSprite(ctx, key, sprite, dx, dy, scale, flip) {
  const img = bakeSprite(key + '@' + scale + (flip ? 'f' : ''), sprite, scale, flip);
  ctx.drawImage(img, Math.round(dx), Math.round(dy));
}

const DIRS = {
  up: { dx: 0, dy: -1 },
  down: { dx: 0, dy: 1 },
  left: { dx: -1, dy: 0 },
  right: { dx: 1, dy: 0 }
};

function tryMove(dir) {
  if (state.moving || state.battle) return;
  state.dir = dir;
  const d = DIRS[dir];
  const nx = state.x + d.dx;
  const ny = state.y + d.dy;
  const t = tileAt(nx, ny);
  if (!PASSABLE[t]) {
    sound.blocked();
    renderField();
    return;
  }
  sound.step();
  state.moving = { dx: d.dx, dy: d.dy, progress: 0, to: { x: nx, y: ny } };
}

function updateMove() {
  if (!state.moving) return;
  state.moving.progress += 0.25;
  if (state.moving.progress >= 1) {
    state.x = state.moving.to.x;
    state.y = state.moving.to.y;
    state.moving = null;
    state.frame = state.frame === 0 ? 1 : 0;
    state.steps++;
    onStepFinished();
  }
}

// 1歩ぶん進み終わった時の処理
function onStepFinished() {
  const t = tileAt(state.x, state.y);

  // 町・村・城では体力が回復する。何度も全滅して心が折れないようにするため
  if (REST_TILE[t]) {
    if (state.hp < state.maxHp) {
      state.hp = state.maxHp;
      updateStatus();
      sound.heal();
      const place = t === 'c' ? 'おしろ' : (t === 'v' ? 'むら' : 'まち');
      setSaveState(place + 'で やすんだ！ HPが かいふく');
    }
    return;   // 安全地帯なので敵は出ない
  }

  checkEncounter();
}

function checkEncounter() {
  const t = tileAt(state.x, state.y);
  const weight = ENCOUNTER_TILE[t] || 0;
  if (weight <= 0) return;
  if (state.steps < 3) return;   // 開始直後にいきなり出ないように
  const chance = state.encounterRate * weight;
  if (Math.random() * 100 < chance) {
    state.battleTerrain = t;
    startBattle(TILE_DIFFICULTY[t] || 1);
  }
}

// 出題する問題を選ぶ。
// 一度間違えた問題を混ぜて出し直すのがこのゲームの学習面の肝で、
// 単に全問をランダムに流すより「解けなかったものが解けるようになる」効果が高い。
function pickQuestion(terrainLevel) {
  // 間違えた問題が溜まっていたら、3回に1回くらいの割合で復習に回す。
  // 直後だと答えを覚えているだけなので、キューの先頭＝いちばん古いものから出す。
  if (state.wrongQueue.length >= 2 && Math.random() < 0.35) {
    const id = state.wrongQueue.shift();
    for (let i = 0; i < state.questions.length; i++) {
      if (state.questions[i].id === id) return state.questions[i];
    }
  }

  let pool = state.questions.filter(function (q) {
    return state.askedIds.indexOf(q.id) === -1;
  });
  if (!pool.length) { state.askedIds = []; pool = state.questions.slice(0); }

  // 地形が険しいほど難しい問題を優先する。該当がなければ全体から選ぶ
  if (terrainLevel) {
    const matched = pool.filter(function (q) {
      return Math.min(3, Math.max(1, q.level || 1)) === terrainLevel;
    });
    if (matched.length) pool = matched;
  }

  const q = pool[Math.floor(Math.random() * pool.length)];
  state.askedIds.push(q.id);
  return q;
}

function renderQuestion(q) {
  $('questionField').textContent = '【' + q.field + '】';
  $('questionText').textContent = q.text;

function answer(selected) {
  const b = state.battle;
  if (!b || b.answered) return;
  b.answered = true;

  const q = b.question;
  const correct = (selected === q.answer);
  const seconds = (Date.now() - b.askedAt) / 1000;

  // ログはここでは送らない。たまってから、まとめて1回だけ送る
  state.pendingLogs.push({
    questionId: q.id,
    selected: selected,
    correct: correct,
    seconds: seconds,
    level: state.level
  });

  recordResult(q.field, correct);

  // 間違えた問題はあとで出し直す。正解できたらキューから1つ抜く
  if (!correct) {
    if (state.wrongQueue.indexOf(q.id) === -1) state.wrongQueue.push(q.id);
  } else {
    const at = state.wrongQueue.indexOf(q.id);
    if (at !== -1) state.wrongQueue.splice(at, 1);
  }

  const buttons = $('choices').querySelectorAll('.choice');
  buttons.forEach(function (btn) {
    btn.disabled = true;
    const idx = Number(btn.dataset.index);
    if (idx === q.answer) btn.classList.add('correct');
    else if (idx === selected) btn.classList.add('wrong');
  });

  let message = '';
  if (correct) {
    const damage = attackFor(state.level);
    b.enemyHp = Math.max(0, b.enemyHp - damage);
    $('enemyHpBar').style.width = ((b.enemyHp / b.enemyMaxHp) * 100) + '%';
    enemyCanvas.classList.add('hit');
    setTimeout(function () { enemyCanvas.classList.remove('hit'); }, 300);
    sound.attack();
    popDamage(damage, 'enemy');
    message = 'せいかい！ ' + escapeHtml(b.enemy.name) + ' に ' + damage + ' の ダメージ！';
  } else {
    state.hp = Math.max(0, state.hp - b.enemyAttack);
    sound.damage();
    popDamage(b.enemyAttack, 'player');
    flashScreen();
    message = '<span style="color:var(--danger)">まちがえた！ ' + escapeHtml(b.enemy.name) + ' の こうげき！ '
      + b.enemyAttack + ' の ダメージ！</span>';
  }

  if (q.note) {
    message += '<span class="note">' + escapeHtml(q.note) + '</span>';
  }
  typeMessage($('battleMessage'), message);
  updateStatus();

  if (state.pendingLogs.length >= 10) flushLogs();

  setTimeout(function () {
    if (state.hp <= 0) { showGameOver(); return; }
    if (b.enemyHp <= 0) { winBattle(); return; }
    $('nextBtn').style.display = 'inline-block';
    $('nextBtn').textContent = 'つぎの もんだいへ';
  }, 700);
}

function winBattle() {
  const b = state.battle;
  enemyCanvas.classList.add('defeated');
  sound.defeat();

  state.exp += b.exp;
  let text = '<span style="color:var(--accent)">' + escapeHtml(b.enemy.name) + ' を たおした！ '
    + b.exp + ' の けいけんち を かくとく！</span>';

  // レベルアップ判定
  const newLevel = Math.max(1, Math.floor(state.exp / state.expPerLevel) + 1);
  if (newLevel > state.level) {
    state.level = newLevel;
    state.maxHp = maxHpFor(state.level);
    state.hp = state.maxHp;   // レベルが上がったら全回復
    text += '<span class="lvup" style="display:block;margin-top:6px">レベルが ' + state.level
      + ' に あがった！ HPが ぜんかい した！</span>';
    setTimeout(function () { sound.levelup(); }, 620);
  }

  typeMessage($('battleMessage'), text);
  $('choices').innerHTML = '';
  $('questionText').textContent = '';
  $('questionField').textContent = '';
  $('nextBtn').style.display = 'inline-block';
  $('nextBtn').textContent = 'ぼうけんに もどる';
  state.battle = null;
  updateStatus();
  flushLogs();
}

function flushLogs() {
  if (!hasServer || state.offline) return;
  if (state.saving) return;
  if (!state.pendingLogs.length && !state.playerName) return;

  // サーバーが1回で受け取れるのは200件まで。溢れた分は次回に回す
  const BATCH = 100;
  const batch = state.pendingLogs.slice(0, BATCH);
  const rest = state.pendingLogs.slice(BATCH);

  const payload = {
    playerName: state.playerName,
    className: state.className,
    level: state.level,
    exp: state.exp,
    logs: batch
  };
  const sending = batch.length;
  state.pendingLogs = rest;
  state.saving = true;

  google.script.run
    .withSuccessHandler(function (res) {
      state.saving = false;
      if (res && res.ok) {
        setSaveState('きろく しました');
      } else {
        // 失敗した分は捨てずに戻して、次のまとめ送りで再挑戦する
        state.pendingLogs = payload.logs.concat(state.pendingLogs);
        setSaveState('あとで ほぞん します');
      }
    })
    .withFailureHandler(function () {
      state.saving = false;
      state.pendingLogs = payload.logs.concat(state.pendingLogs);
      setSaveState('あとで ほぞん します');
    })
    .saveSession(payload);

  if (sending) setSaveState('きろくちゅう...');
}

URLを生徒に配る

発行されたURLを開くと、問題・ログ・進捗・設定の4つのシートが自動で作られ、サンプルの地理問題30問が入ります。GASエディタで関数を実行する必要はありません。あとはURLを生徒に配るだけです。

USAGE

使い方

生徒の操作はシンプルです。先生の準備も、問題を書き足すだけで終わります。

生徒がやること

URLを開いて名前とクラスを選び、「ぼうけんを はじめる」を押します。あとは方向キー（または画面下の十字ボタン）で歩き、敵が出たら4択に答えるだけです。キーボードの1〜4キーでも選べます。次の授業でも同じ名前で入れば、レベルと経験値が続きます。

問題を差し替える

「問題」シートに1行足すだけで出題されます。列の意味は次の通りです。

列入れるもの
問題ID他と重複しない番号（Q31 など）
分野「日本の地形」など。分野ごとに出てくる敵が変わります
難易度1〜3。1は草原、2は森、3は砂漠で出ます。数字が大きいほど敵も強くなります
問題文そのまま画面に出ます
選択肢1〜44つ埋めなくても、2つ以上あれば出題されます
正解番号1〜4のどれが正解か
解説答え合わせのときに下に出ます。空でも構いません

難易度や出題範囲を変える

「設定」シートで、クラス名の一覧、敵の出やすさ、レベルアップに必要な経験値、効果音のON/OFFを変えられます。「出題分野」に分野名を書くと、その分野だけを出題できます（例：定期テスト前に「日本の産業」だけ出す）。空欄なら全分野から出ます。

つまずきを見る

「ログ」シートに解答が1行ずつ貯まります。分野の列でフィルタをかけたり、正誤の列で集計したりすると、クラスがどこを落としているかが見えます。解答にかかった秒数も残るので、迷った問題も分かります。

見えません。アプリは先生のアカウント名義で動く設定（次のユーザーとして実行：自分）なので、生徒はスプレッドシート自体を開けません。生徒に見えるのはゲーム画面だけです。
35人が一斉に使っても大丈夫ですか？
大丈夫なように作ってあります。問題は起動時にまとめて読み込んでブラウザ側に持たせ、解答の記録は10問ごとにまとめて送る設計です。1問ごとにサーバーへ通信する作りだと人数が増えたときに詰まりますが、この作りなら生徒1人あたりの通信は授業1コマで数回に収まります。
Chromebookで動きますか？
動きます。ブラウザだけで動くので、インストールは不要です。方向キーと画面タッチの両方に対応しています。
教室で音が鳴ると困ります
「設定」シートの「効果音」を OFF にすると、既定で音が鳴らなくなります。生徒側もタイトル画面のボタンでいつでも切り替えられます。
地理以外の教科でも使えますか？
使えます。問題シートの中身を入れ替えれば、歴史でも理科でも英単語でも同じように動きます。分野名を変えると出てくる敵も変わります。
通信が切れたらどうなりますか？
サーバーにつながらないときは「おためしモード」に切り替わり、内蔵の問題でゲームだけは続けられます。授業中に止まってしまわないための作りです。ただしこの間の解答は記録されません。
生徒の進捗をリセットしたいのですが
「進捗」シートの該当する行を削除すれば、その生徒はレベル1から始まります。クラスごと消したい場合は行をまとめて削除してください。
マップや敵を自分で変えられますか？
変えられます。chiri.html の中に、マップは1文字＝1マスの文字列（g=草原 f=森 m=山 w=海 r=道 t=町 c=城 d=砂漠 b=橋 v=村）、キャラと地形は1文字＝1ドットのドット絵として書いてあります。文字を書き換えれば地形も絵も変わります。
