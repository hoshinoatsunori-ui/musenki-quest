# 地理クエスト

ファミコン風のフィールドを歩き、敵に出会うと 4 択の地理問題が出る学習 RPG です。
Google スプレッドシート + Google Apps Script (GAS) のウェブアプリとして動き、生徒は
配布された URL をブラウザで開くだけで遊べます。問題は先生がスプレッドシートに 1 行
書き足すだけで差し替えられ、誰がどの問題をどれだけの時間で解いたかが自動で記録されます。

- バージョン: 1.8
- ランタイム: GAS V8 / タイムゾーン Asia/Tokyo
- 想定環境: Chromebook などのブラウザ（インストール不要・キーボードとタッチの両対応）
- 作者: kimura yoshiki（[note](https://note.com/cozy_auklet6005) / [X @kimura_0314](https://x.com/kimura_0314)）

## リポジトリの構成

| ファイル | 役割 |
| --- | --- |
| `code.gs` | GAS 側のサーバーコード。シートの初期化、問題の読み出し、解答ログと進捗の保存。 |
| `chiri.html` | ゲーム本体（1 ファイル完結のクライアント）。マップ・ドット絵・効果音・バトル処理をすべて内包。 |
| `appsscript.json` | GAS のマニフェスト。V8 ランタイム、ウェブアプリ設定。 |
| `lp.html` | note などで配布するための紹介ページ（ランディングページ）。上記 3 ファイルのコードをそのまま埋め込んで配布する。 |

> **ファイル名について**
> `code.gs` の `doGet()` は `HtmlService.createTemplateFromFile('chiri')` を呼びます。GAS 側の
> HTML ファイル名もこのリポジトリと同じ **`chiri`**（`chiri.html`）にしてください。別の名前に
> したい場合は `doGet()` の引数も合わせて変更します。`.gs` のファイル名は GAS の動作に影響しない
> ので、最初から入っている `コード.gs` にそのまま貼り付けて構いません。

> **`lp.html` との同期**
> `lp.html` にはコードビューとして `appsscript.json` / `code.gs` / `chiri.html` の全文が
> エスケープされた状態で埋め込まれています（3 ファイルとも内容は完全一致）。
> ソースを直したら `lp.html` 側の埋め込みも更新しないと、配布物が食い違います。

## セットアップ

1. **スプレッドシートを新規作成**する（例: `地理クエスト_データ`）。中身は空のままで構いません。
2. メニューの **拡張機能 → Apps Script** を開く。
3. 3 つのファイルを貼り付ける。
   - `code.gs` … 最初から入っている `コード.gs` の中身を全部消して貼り付け（`.gs` のファイル名は変えなくても動きます）
   - `chiri.html` … 左の「ファイル」＋から **HTML** を選び、ファイル名を `chiri` にして貼り付け
   - `appsscript.json` … 「プロジェクトの設定」で *appsscript.json マニフェスト ファイルをエディタで表示する* にチェックを入れると編集できる
4. **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 次のユーザーとして実行: **自分（先生のアカウント）**
   - アクセスできるユーザー: 校内利用なら「同じドメイン内の全員」
   - 初回は「このアプリは確認されていません」の警告が出ますが、自作アプリなので `詳細` → `（安全ではないページ）に移動` から許可します。
5. **発行された URL を開く**と、`問題` / `ログ` / `進捗` / `設定` の 4 シートが自動作成され、
   サンプルの地理問題 30 問が入ります。GAS エディタで関数を手動実行する必要はありません。
   あとは URL を生徒に配るだけです。

> リポジトリ内の `appsscript.json` は `"access": "MYSELF"` になっています。実際の公開範囲は
> デプロイ画面での指定が優先されるので、配布時にそちらを設定してください。

> **既に旧バージョンをデプロイしている場合**
> 1.8 までは `doGet()` が `無題` という名前の HTML を読み込んでいました。GAS プロジェクト側の
> HTML ファイルを `無題` から `chiri` にリネームし（`code.gs` を貼り直す場合は先にリネームする）、
> **デプロイ → デプロイを管理 → 鉛筆アイコン → バージョン「新バージョン」** で再デプロイしてください。
> リネームを忘れると `doGet()` がテンプレートを見つけられず、URL を開いてもエラーになります。
> URL はデプロイを管理から更新すれば変わらないので、生徒に配り直す必要はありません。

## スプレッドシートの構成

`setup()`（初回アクセス時に `ensureInitialized_()` が自動で呼びます）が次の 4 シートを作ります。

### 問題

| 列 | 内容 |
| --- | --- |
| 問題ID | 他と重複しない ID（`Q31` など） |
| 分野 | `日本の地形` など。分野ごとに出てくる敵の見た目が変わる |
| 難易度 | 1〜3。1 は草原、2 は森、3 は砂漠で出やすくなる |
| 問題文 | そのまま画面に表示 |
| 選択肢1〜4 | 2 つ以上埋まっていれば出題される |
| 正解番号 | 1〜4 |
| 解説 | 答え合わせのときに表示。空欄可 |

問題文が空、正解番号が未設定、選択肢が 2 つ未満、正解に指定した選択肢が空欄 —— のいずれかに
当たる行は読み込み時に除外されます（永久に正解できない問題を出さないため）。

### ログ

`日時 / クラス / 名前 / 問題ID / 選んだ番号 / 正誤 / 解答秒数 / レベル` が 1 解答 1 行で貯まります。
分野でフィルタしたり正誤で集計したりすると、クラス全体のつまずきが見えます。

### 進捗

`クラス / 名前 / レベル / 経験値 / 最終プレイ日時`。同じ名前・同じクラスで入り直すと続きから遊べます。
リセットしたいときは該当行を削除します。

### 設定

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| クラス名 | `1年A組,1年B組,1年C組,1年D組` | カンマ区切り。タイトル画面の選択肢になる |
| エンカウント率 | `8` | 1 歩あたり敵に出会う確率（%）。1〜60 に丸められる |
| レベルアップ必要経験値 | `20` | レベルが 1 上がるのに必要な経験値 |
| 出題分野 | 空欄 | 空欄なら全分野。分野名をカンマ区切りで書くとその分野だけ出題 |
| 効果音 | `ON` | `OFF` にすると既定で無音（生徒側でも切り替え可） |

## ゲームの仕組み

### フィールド

- マップは 48×48 マスの 1 文字＝1 マスの文字列（`chiri.html` の `MAP`）。
  `w`=海 `g`=草原 `f`=森 `m`=山 `r`=道 `b`=橋 `t`=町 `c`=城 `v`=村 `d`=砂漠
- 海と山は通れません。川は橋（`b`）を通らないと渡れません。
- 城 1・町 4・村 3。**町 / 村 / 城は敵が出ず、HP が全回復する安全地帯**です。
- スタート地点は城（`x=22, y=22`）。全滅しても経験値は残り、城に戻って再開します。

### エンカウントとバトル

- 地形ごとの出やすさ（`ENCOUNTER_TILE`）: 草原 ×1、森 ×1.6、砂漠 ×2.2。道・橋・町・村・城は 0。
  歩き始めの 3 歩は必ず安全です。
- 地形ごとの難易度（`TILE_DIFFICULTY`）: 草原 1、森 2、砂漠 3。奥へ行くほど強い敵と難しい問題が出ます。
- **正解すると敵にダメージ、間違えると自分がダメージ**。
  - プレイヤー: `最大HP = 20 + レベル×5`、`攻撃力 = 8 + レベル×2`
  - 敵: `HP = 難易度×10`、`攻撃力 = 3 + 難易度×2`、`経験値 = 難易度×3 + 2`
- 敵は分野ごとに割り当てられます（スライム / コウモリ / いわゴーレム / マタンゴ / まおう）。
- レベルアップ時は HP が全回復します。

### 出題の選び方

- 未出題の問題からランダムに選び、現在の地形の難易度に合う問題を優先します。全部出し切ると出題履歴をリセット。
- **間違えた問題はキューに積まれ、約 35% の確率で復習として出し直されます**（直後だと答えを覚えているだけなので、いちばん古いものから）。正解できるとキューから外れます。
- メニュー（`■` ボタン）の「ぼうけんの しょ」で、分野別の正答率を色分けして確認できます。

### 画像・音声ファイルを使わない

- キャラ・敵・地形はすべて「1 文字＝1 ドット」の文字列データとして `chiri.html` に埋め込み、Canvas に直接描画しています。
- 効果音は Web Audio API で矩形波・ノイズをその場で合成しています。
- そのため**貼り付けるファイルは 3 つだけ**で完結し、画像も音声もアップロード不要です。

## 同時アクセスへの配慮（設計の要点）

35 人〜のクラスが一斉に使っても GAS の同時実行上限を食いつぶさないように作られています。

- **通信は「起動時に 1 回」と「10 問ごと / 終了時」だけ。** 問題は起動時に全件取得してブラウザ側に持たせ、
  以後の出題では通信しません。
- 解答ログは `state.pendingLogs` に貯め、10 件たまった時・バトル勝利時・ゲームオーバー時・
  タブを閉じる時（`pagehide` / `visibilitychange`）にまとめて送ります。
- 送信は 1 回 100 件ずつ、サーバー側の受け取り上限は 200 件。**保存に失敗した分は捨てずにキューへ戻し、次回に再送**します。
- 書き込みは `LockService` で直列化。ロックが 8 秒で取れなければ失敗を返し、クライアントが次回まとめて送り直します。
- 初期化（`ensureInitialized_`）も、準備が必要なときだけロックを取るので、授業開始直後に全員が同時アクセスしてもサンプル問題が二重に入りません。
- サーバーにつながらないときは**おためしモード**（内蔵の 6 問）に切り替わり、授業中に止まりません。ただしこの間の解答は記録されません。

## セキュリティ上の配慮

- ウェブアプリを「次のユーザーとして実行: 自分」でデプロイするため、**生徒はスプレッドシート本体を開けません**。見えるのはゲーム画面だけです。
- 名前などシートに書き込む値は `sanitizeCell_()` で先頭の `= + - @` を無害化し、制御文字を除去、60 文字で切り詰めます（数式インジェクション対策）。
- 画面に出す文字列は `escapeHtml()` を通します。

## カスタマイズ

- **問題の差し替え**: `問題` シートに行を足すだけ。地理以外（歴史・理科・英単語など）にも入れ替えられます。
- **出題範囲の限定**: `設定` シートの `出題分野` に分野名を書くと、その分野だけ出題されます（例: テスト前に「日本の産業」だけ）。
- **難易度調整**: `エンカウント率` と `レベルアップ必要経験値` で歩きやすさ・成長速度を変えられます。
- **マップ / ドット絵**: `chiri.html` の `MAP`、`SPR_TILE`、`SPR_ENEMY` などの文字列を書き換えれば地形も絵も変わります。
- **敵の種類**: `ENEMY_TYPES` に追加すると、分野が増えたときに順番に割り当てられます。

## 操作方法

| 場面 | 操作 |
| --- | --- |
| タイトル | 名前を入力しクラスを選んで「ぼうけんを はじめる」。Enter でも開始 |
| フィールド | 矢印キー / `WASD`、または画面下の十字ボタン（長押しで歩き続ける） |
| メニュー | 十字キー中央の `■` ボタン → 「ぼうけんの しょ」 |
| バトル | 選択肢をクリック、またはキーボードの `1`〜`4`。`Enter` で次へ |
| 効果音 | タイトル画面の `♪ おと` ボタンでいつでも切り替え |

## ローカルでの動作確認

`chiri.html` をそのままブラウザで開くと、`google.script.run` が無いことを検知して
**おためしモード**（内蔵 6 問・記録なし）で起動します。GAS にデプロイしなくても、
マップやバトルの見た目は確認できます。
