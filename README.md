# 無線クエスト2

無線に関する4択クイズを解いてモンスターにダメージを与える、ドラクエ風の学習RPGです。
ジャンルごとに用意された道のりを進み、最後に待つボスを倒すと、そのジャンルの
**スキルを習得**したことになります。Google スプレッドシート + Google Apps Script (GAS) の
ウェブアプリとして動き、参加者は配布された URL をブラウザで開くだけで遊べます。

- バージョン: 2.1
- ランタイム: GAS V8 / タイムゾーン Asia/Tokyo
- 想定環境: PC・タブレット・スマホのブラウザ（インストール不要）

---

## このリポジトリについて

| | |
| --- | --- |
| リポジトリ名 | `musenki-quest` |
| アプリ名 | 無線クエスト2 |
| HTML ファイル名 | `musen.html`（GAS 上でも `musen`） |

名前が3か所で少しずつ違いますが、そのままにしています。`server.gs` の `doGet()` が
読み込むのは **`musen`** なので、動作に関わるのは HTML ファイル名だけです。

このリポジトリは以前 `chiri-quest`（地理クエスト）でした。地理クエストは
**`chiri-quest` ブランチ**にそのまま残してあります。無線クエスト2とはプラットフォーム
（Apps Script ＋ スプレッドシート）が同じなだけで、コードの流用はありません。

| ブランチ | 中身 |
| --- | --- |
| `main` | 無線クエスト2 |
| `chiri-quest` | 地理クエスト 1.8（置き換え前の最終状態） |
| `claude/chiri-quest-readme-3693tw` | 地理クエストに README を足した作業ブランチ |

## 企画のねらいと、それをどう実装したか

| ねらい | 実装 |
| --- | --- |
| クイズに正解してモンスターにダメージ | 1問＝1回の攻撃。正解するとモンスターのHPが減る |
| 難易度が高いものほどモンスターが強い | 問題の難易度1〜3がそのまま敵のHP・攻撃力・経験値になる |
| ボスまで冒険を進め、勝つとスキル習得 | エリアごとの地図を歩いてアイテムを3つ集め、ボスを倒すとスキルを獲得し次のジャンルが開く |
| **各エリアに地図がある** | 地球の大陸をモチーフにした地図を歩く。エリアが進むほど広くなり、最後は日本列島 |
| **アイテムはたからばこ** | 開けるかどうかを一度たずねる。いくつかは中ボス（化け箱）が化けている |
| **制限時間があり、早いほど強い** | 1問ごとに秒読み。残り時間がそのままダメージの倍率（等倍〜0.5倍）になる |
| **4択は間違えても再度回答できる** | 誤答した選択肢だけが閉じ、同じ問題に答え直せる。誤答するたび自分がダメージを受け、与えるダメージも下がる |
| 経験値が累積してレベルアップ | モンスター撃破で経験値。一定量ごとにレベルが上がり、最大HPと攻撃力が伸びる |
| 複数人のプレイ状況を共有 | 「みんなの状況」に全員のレベル・経験値・取得スキル・投稿数が並ぶ |
| クイズはスプレッドシートに事前準備 | 「問題バンク」に1行1問。45問を初期投入 |
| ユーザーも投稿でき、大きな経験値がもらえる | ゲーム内の投稿フォームから投稿。**投稿した時点で経験値120**（設定で変更可） |

## ファイルの構成

| ファイル | 役割 |
| --- | --- |
| `server.gs` | GAS 側のサーバーコード。シートの準備、問題の読み出し、進行の保存、投稿の受付。 |
| `questions.gs` | 初期投入する45問。問題を差し替えるときはこのファイルだけ触れば済みます。 |
| `maps.gs` | エリアごとの地図とたからばこ。地形は1文字＝1マスの文字列です。 |
| `musen.html` | ゲーム本体。画面・モンスターの絵・バトル処理をすべて内包した1ファイル。 |
| `appsscript.json` | GAS のマニフェスト。V8 ランタイム、ウェブアプリ設定。 |

GAS はプロジェクト内の `.gs` ファイルをまとめて読み込むので、`server.gs` は
`questions.gs` と `maps.gs` の中身をそのまま参照できます。ファイル名や貼り付ける順番は問いません。

## セットアップ

1. **スプレッドシートを新規作成**する（例: `無線クエスト2_データ`）。中身は空のままで構いません。
2. メニューの **拡張機能 → Apps Script** を開く。
3. 5つのファイルを貼り付ける。
   - `server.gs` … 最初から入っている `コード.gs` の中身を全部消して貼り付け（`.gs` のファイル名は変えなくても動きます）
   - `questions.gs` … 左の「ファイル」＋から **スクリプト** を選び、ファイル名を `questions` にして貼り付け
   - `maps.gs` … 同じく **スクリプト** を選び、ファイル名を `maps` にして貼り付け
   - `musen.html` … 左の「ファイル」＋から **HTML** を選び、ファイル名を `musen` にして貼り付け。この名前は `server.gs` の `doGet()` が読み込む名前なので、変える場合は両方そろえてください
   - `appsscript.json` … 「プロジェクトの設定」で *appsscript.json マニフェスト ファイルをエディタで表示する* にチェックを入れると編集できる
4. **デプロイ → 新しいデプロイ → ウェブアプリ**
   - 次のユーザーとして実行: **自分（運営者のアカウント）**
   - アクセスできるユーザー: 組織内で使うなら「同じドメイン内の全員」
   - 初回は「このアプリは確認されていません」の警告が出ますが、自作アプリなので `詳細` → `（安全ではないページ）に移動` から進んで許可します。
5. **発行された URL を開く**と、5つのシートが自動で作られ、`questions.gs` の45問が入ります。
   あとは URL を参加者に配るだけです。

> リポジトリ内の `appsscript.json` は `"access": "DOMAIN"` にしてあります。実際の公開範囲は
> デプロイ画面での指定が優先されるので、配布時にそちらを設定してください。

セットアップ後、スプレッドシートを開き直すと **「無線クエスト2」メニュー** が出ます。
シートの再準備と、投稿の承認・却下をここから行えます。

## シートの構成

### 問題バンク

事前に用意する問題です。1行1問。

| 列 | 内容 |
| --- | --- |
| 問題ID | 他と重複しない ID（`W101` など） |
| ジャンル | 下記5つのいずれか。ここが冒険のエリアになります |
| 難易度 | 1〜3。そのまま敵の強さになります |
| 問題文 | そのまま画面に出ます |
| 選択肢A〜D | 4つとも必要です |
| 正解 | `A`〜`D` |
| 解説 | 答え合わせのときに出ます。空欄可 |
| 作成者 | 表示用。空欄可 |
| 公開 | `TRUE` のときだけ出題されます |

ジャンルは次の5つで、この順に開放されます。

| ジャンル | ボス | 習得スキル |
| --- | --- | --- |
| 電波の基礎 | 電離層ドラゴン | 伝搬解析 |
| 運用と通信術 | 混信の亡霊 | 交信術 |
| アンテナ | 定在波のぬし | 空中線調整 |
| 無線工学 | 発振の魔人 | 回路設計 |
| 電波法規 | 条文の守護者 | 法令遵守 |

初期の45問は5ジャンル×難易度1〜3×各3問で、**第四級〜第三級アマチュア無線技士の入門帯**を
想定しています。中身は `questions.gs` にまとまっているので、丸ごと別の分野に差し替える
こともできます。ジャンルを増やしたいときは `server.gs` の `AREAS` に足します。ボス名・
スキル名・モンスターの見た目・色もここで決めています。

### 投稿箱

参加者が投稿した問題が貯まります。`審査` 列が **`承認`** になった問題だけが出題に混ざります。
問題バンクへコピーする必要はありません。

承認のしかたは2通りです。

- **投稿箱シートで対象の行を選び、メニュー「無線クエスト2 → 選択した投稿を承認する」**
- 設定シートの `投稿の自動承認` を `ON` にすると、投稿がそのまま出題に混ざります（審査なし）

### オペレーター

参加者ごとの記録です。`ハンドル / レベル / 経験値 / 進行 / 取得スキル / 撃破数 / 正答数 /
回答数 / 投稿数 / 最終交信`。

`進行` は `電波の基礎:7,アンテナ:5` のようにエリアごとの数値で、どのアイテムを取ったかを
ビットで表します（1つめ＝1、2つめ＝2、3つめ＝4）。`7` は3つそろった状態、`5` は
1つめと3つめだけ持っている状態です。ボスを倒したかどうかは `取得スキル` で分かります。

進捗をリセットしたいときは、その人の行を削除します。

### 交信ログ

1回の解答ごとに `日時 / ハンドル / ジャンル / 問題ID / 誤答数 / 所要秒 / 結果` が残ります。
誤答数の多い問題を集計すると、みんながどこでつまずいているかが見えます。

### 設定

| 項目 | 既定値 | 説明 |
| --- | --- | --- |
| 投稿経験値 | `120` | 1問投稿したときにもらえる経験値 |
| 投稿の自動承認 | `OFF` | `ON` で投稿がすぐ出題に混ざる |
| 1日の投稿上限 | `5` | 1人が1日に投稿できる問題数 |
| レベルアップ経験値 | `50` | レベルが1つ上がるのに必要な経験値 |
| 制限時間 | `20` | 1問に答えられる秒数。早く答えるほど大きなダメージになります |
| ランキング表示人数 | `20` | 「みんなの状況」に出す人数 |

## ゲームの流れ

1. **ハンドルを入れて交信開始**。同じハンドルで入り直すと続きから遊べます。
2. **基地局**でエリアを選ぶ。最初は「電波の基礎」だけが開いています。
3. **地図**を歩く。矢印キー・WASD、または画面の十字ボタンで動きます。
4. **たからばこ**を開けてアイテムを集めます。化け箱なら中ボスとの戦闘です。
5. **アイテムを3つ集める**とボスのマスに入れるようになります。
6. ボスを倒すと**スキルを習得**し、次のエリアが開きます。

### 地図

地形は**地球の大陸**をモチーフにしていて、**エリアが進むほど地図も陸地も広くなり**、
最後は**日本列島**にたどりつきます。

| 順 | ジャンル | 地図 | 広さ | 歩けるマス | 化け箱 |
| --- | --- | --- | --- | --- | --- |
| 1 | 電波の基礎 | オーストラリア大陸 | 13×9 | 60 | 1個 |
| 2 | 運用と通信術 | アフリカ大陸 | 15×11 | 75 | 1個 |
| 3 | アンテナ | 南アメリカ大陸 | 17×11 | 88 | 2個 |
| 4 | 無線工学 | ユーラシア大陸 | 19×13 | 127 | 2個 |
| 5 | 電波法規 | **日本列島** | 23×15 | 136 | 3個 |

| マス | 記号 | 意味 |
| --- | --- | --- |
| 海 | `~` | 通れません |
| 山 | `#` | 通れません |
| 平地 | `,` | 歩くと敵が出ます |
| 道 | `.` | 安全。敵は出ません |
| 上陸地点 | `S` | ここから始まります |
| たからばこ | `1` `2` `3` | 開けるとアイテム、または化け箱との戦闘 |
| ボス | `B` | たからばこを3つ開けるまで入れません |

道中の敵は、そのエリアで歩き始めて3歩めから、平地1歩につき24%の確率で出ます。

### たからばこと化け箱

たからばこのマスに乗ると、**開けるかどうかの確認メニュー**が出ます（`Enter` であける、
`Esc` でやめる）。やめてもその場に残るので、あとから開け直せます。

- ふつうのたからばこ … 開けるとその場でアイテムが手に入ります
- **化け箱** … 開けると中ボスとの戦闘になります。倒すと中身が手に入ります

どのたからばこが化け箱かは `maps.gs` の `mimics` で決めています（`0` がひとつめ）。
エリアが進むほど化け箱が増え、最後の日本列島では3つとも化け箱です。

### 戦闘の計算

| 項目 | 式 |
| --- | --- |
| 最大HP | `40 + レベル×8` |
| 攻撃力 | `16 + レベル×4` |
| 道中の敵 | HP `30 + 難易度×20` / 攻撃力 `5 + 難易度×2` / 経験値 `10 + 難易度×8` |
| 化け箱（中ボス） | HP `40 + 難易度×20` / 攻撃力 `5 + 難易度×2` / 経験値 `16 + 難易度×8` |
| ボス | HP 160 / 攻撃力 12 / 経験値 90 |

相手の難易度は、道中がアイテム2つめまで `1`・それ以降 `2`、化け箱が `2`、ボスが `3` です。

与えるダメージは **攻撃力 × 速さ倍率 × 誤答倍率** で決まります。

**速さ倍率** — 早く答えるほど大きくなります。`0.5 + 0.5 × (のこり時間 ÷ 制限時間)`。

| 答えるまで | 倍率 |
| --- | --- |
| 即答 | 1.00 |
| 制限時間の半分 | 0.75 |
| 時間ぎりぎり | 0.50 |
| 時間切れ後 | 0.50（下限） |

制限時間は設定シートで変えられます（既定20秒）。

**誤答倍率** — **誤答しても答え直せます**が、間違えるほど威力が落ちます。

| 誤答回数 | 倍率 |
| --- | --- |
| 0（一発正解） | 1.00 |
| 1 | 0.60 |
| 2 | 0.35 |
| 3 | 0.15（最低1ダメージ） |

誤答のたび、また時間切れのときにも敵の攻撃力ぶんのダメージを受けます。**時間切れになっても
答えは選べます**（倍率が下限に張り付くだけです）。誤答しても秒読みは止まりません。

HPが0になると基地局へ撤退します。**経験値と、手に入れたアイテムは残ります。**
基地局に戻るとHPは全回復します。

### 出題の選び方

そのエリアのジャンルから、まだ出していない問題を優先して選びます。相手の難易度に合う問題が
あればそこから、なければジャンル内のどれかから出します。全部出し切ると出題履歴をリセットします。

## 問題を投稿してもらう

ゲーム内の「問題を投稿する」からジャンル・難易度・問題文・選択肢4つ・正解・解説を送ります。
**送った時点で経験値が入ります**（既定120。モンスター1体が18〜34なので、投稿1回は
道中の数体ぶんに相当します）。

経験値めあての空投稿を防ぐため、サーバー側で次を弾いています。

- 問題文が8文字未満
- 選択肢が4つ埋まっていない、または同じ選択肢が混ざっている
- 問題バンクまたは投稿箱に、同じ問題文がすでにある
- その人の当日の投稿数が上限に達している

## 同時アクセスへの配慮

- サーバーを呼ぶのは **起動時・モンスター撃破時・撤退時・投稿時・一覧更新時** だけです。
  1問ごとには通信しません。
- 書き込みは `LockService` で直列化し、取れなければ失敗を返してクライアントが次回に送り直します。
- 送信に失敗したログは捨てずにキューへ戻します。タブを閉じるとき（`pagehide` /
  `visibilitychange`）にも送ります。
- 保存時、経験値・レベル・進行・スキルは**大きいほうを採用**します。通信の行き違いで
  記録が巻き戻るのを防ぐためです。
- 初期化は準備が必要なときだけ鍵を取るので、同時に開いても初期問題が二重に入りません。

## セキュリティと信頼モデル

- ウェブアプリを「次のユーザーとして実行: 自分」でデプロイするため、**参加者は
  スプレッドシート本体を開けません**。見えるのはゲーム画面だけです。
- シートに書く値は先頭の `=` `+` `-` `@` を無害化し、制御文字を除去して長さを切り詰めます
  （数式インジェクション対策）。画面に出す文字列はすべてエスケープします。
- 戦闘の判定はブラウザ側で行い、結果をサーバーに送る作りです。ブラウザを操作すれば
  経験値を偽装できるので、**成績評価そのものには使わず**、部内・校内の学習用途を想定しています。
  厳密さが要るなら、`交信ログ` の誤答数と所要秒を突き合わせてください。

## カスタマイズ

- **問題の差し替え**: 「問題バンク」に行を足すだけ。無線以外の分野にも入れ替えられます。
  シートを作り直すたびに入る初期問題を変えたいときは `questions.gs` を書き換えます。
- **ジャンル / ボス / スキル**: `server.gs` の `AREAS` を編集します。`shape` に指定できるのは
  `blob` `ghost` `wisp` `bat` `crystal` `golem` `tower` `dragon` の8種類、`hue` は色相（0〜360）です。
- **地図とたからばこ**: `maps.gs` を書き換えます。どの行も同じ長さにして、`S` から `1`・`2`・`3`・`B`
  すべてに歩いて行けることを必ず確かめてください（海や山で囲むと詰みます）。
- **化け箱**: `maps.gs` の `mimics`。`[]` にすると、そのエリアは全部ふつうのたからばこになります。
- **集めるアイテムの数**: `server.gs` の `ITEMS_PER_AREA`（既定3）。
- **制限時間**: 設定シートの `制限時間`。倍率のカーブは `musen.html` の `speedRate`。
- **モンスター**: `server.gs` の `MOBS` に名前・見た目・難易度を足します。
- **強さのバランス**: `musen.html` の `maxHpFor` / `powerFor` / `foeStats` / `damageRate` / `speedRate`。
- **敵の出やすさ**: `musen.html` の `arriveAt` にある `0.24`。
- **主人公とたからばこの絵**: `musen.html` の `warriorArt` と `chestArt`。
- **モンスターの絵**: `musen.html` の `SHAPES` に SVG を書き足せば新しい見た目が増えます。
  画像ファイルは使っていないので、貼り付けるファイルは5つのままです。

## ローカルでの動作確認

`musen.html` をそのままブラウザで開くと、`google.script.run` が無いことを検知して
**おためしモード**（内蔵6問・3エリア・地図つき・記録なし）で起動します。主人公は剣と盾を持った
戦士で、地図の上を1マスずつ歩きます。GAS にデプロイ
しなくても、地図の探索とバトルの動きは確認できます。
